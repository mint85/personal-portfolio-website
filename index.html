// projectsThings I have built

Small, focused apps I actually use, plus two full-stack projects from my bootcamp days that are still running.

  • Simple Tip

    live

    A tidy little tip calculator for the moment between the bill and the goodbye. An installable PWA that works fully offline: no ads, no tracking, no network calls. Phone-keypad style bill entry, tip and split steppers, and instant per-person totals. Built with vanilla JavaScript and a service worker.

    vanilla JS · service worker · PWA · GitHub Pages

    Live site for Simple Tip Code for Simple Tip

  • Summit Benchmark

    in progress

    Built so you can keep an eye on altitude in the mountains in real time without a cell signal. An offline-first PWA that shows your live elevation from GPS and calibrates against USGS ground-truth data, made for hikes in national parks with no service. In progress: session logging and elevation charts are on the way.

    vanilla JS · Geolocation API · USGS data · PWA · Netlify

    Live site for Summit Benchmark Code for Summit Benchmark

  • Disc Golf Course Explorer

    live

    A full-stack app built with MongoDB, Express, and EJS templates that displays a catalogue of disc golf courses, with detailed info and photos for each one. Signed-in users can create, edit, and manage course entries backed by a MongoDB database.

    Node · Express · MongoDB · EJS · Heroku

    Live site for Disc Golf Course Explorer Code for Disc Golf Course Explorer

  • Photo Wall

    live

    A Python/Django app that lets users upload photos to build a digital "wall," with photos stored in a linked AWS S3 bucket. Create an account to start, or use the example wall to look around.

    Python · Django · PostgreSQL · AWS S3 · Heroku
